# Nova Platform Scaffold

This scaffold is attached to the current prototype and is intended for gradual migration.

- `backend/`: NestJS module map and realtime gateway skeleton.
- `flutter_app/`: Flutter screen map and app shell skeleton.
- `../../outputs/telegram-suite.html`: Current live prototype, rebranded to Nova.
- `../../outputs/nova-database-schema.sql`: PostgreSQL baseline schema.
- `../../outputs/nova-api-contract.yaml`: REST API contract.

The next implementation step is to turn each skeleton module into real NestJS services/controllers and each Flutter placeholder screen into production UI.
